Precision Online Graph Editor & Visualizer for Competitive Programming

CP Graph Visualizer & Editor is a free, open-source browser and desktop tool designed for Codeforces, AtCoder, CSES, LeetCode, USACO, and computer science students. Paste edge lists, tree parent arrays, adjacency matrices, or multi-testcase inputs to visualize graphs cleanly with collision-free weights and step-by-step algorithm tracing.

Core Capabilities

Smart Competitive Programming Input Auto-detects headerless edge lists, N/M headers, LeetCode 2D arrays, AtCoder tree parent arrays, isolated vertices, primed IDs (1', 2'), weighted nodes, and multi-testcase inputs.
String & Numeric Weights Edges and nodes support integers, decimals, negatives, characters, booleans, and custom labels with bidirectional sync and C++/Python code export.
Overlap-Free Layouts & Weight Badges Automatic collision avoidance steers weight badges clear of edge crossings, vertices, and floating Canvas Notes across Force Physics, Tree, DAG, Bipartite, Circular, and Grid layouts.
17+ Step-by-Step Algorithms Inspect live playback traces for BFS, DFS, Dijkstra, Bellman-Ford, Kahn's Topological Sort, Tarjan's SCC, Bridges & Articulation Points, Kruskal & Prim MST, Bipartite Matching, Eulerian Trail, Tree Diameter, and LCA.
Freehand Lasso & Batch Editing Draw a lasso loop or multi-select vertices and edges to reposition subgraphs together, update colors, or assign batch weights in one step.
Offline Desktop & Export Includes bundled JetBrains Mono typography, Canvas scratchpad notes, high-resolution PNG/SVG export, shareable URL state links, and native installers for Windows, macOS, and Linux.
